# Система анализа протоколов проектной команды

Веб-приложение для хранения протоколов встреч, извлечения решений и поручений, а также ведения реестра замечаний к документам. Анализ выполняется встроенным модулем `MockNeuralAnalyzer`, который имитирует работу нейросети и может быть заменён на реальную модель.

## Возможности

- Добавление протоколов с датой, списком участников и кратким описанием.
- Автоматический анализ текста: выделение решений, поручений с ответственными и сроками, коррекций и неточностей.
- Реестр поручений с возможностью отмечать выполнение.
- Повторный анализ протокола после правок.
- Современный интерфейс со списком документов и детальной страницей.

## Запуск проекта

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Запустите сервер разработки Flask:

   ```bash
   flask --app run --debug run
   ```

   Приложение будет доступно по адресу <http://127.0.0.1:5000>.

3. Для использования в продакшене замените `MockNeuralAnalyzer` на обращение к настоящей ML-модели или API.

## Структура

- `app/models.py` — ORM-модели протоколов, решений, поручений и коррекций.
- `app/neural_analysis.py` — модуль псевдо-нейросетевого анализа текста.
- `app/routes.py` — HTTP-маршруты и обработчики.
- `app/templates/` — HTML-шаблоны интерфейса.
- `app/static/` — стили.
- `run.py` — точка входа приложения.

```

Поручить Иванову подготовить план внедрения срок: 15.06.2024.
Петров должен настроить сервер до 20.06.2024.
Исправить неточность в отчете о рисках.
```
